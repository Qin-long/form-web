# 文件上传组件功能说明

## 概述
文件上传组件支持两种文件类型：图片文件和文档文件，每种类型都有不同的格式限制、大小限制和上传配置。

## 文件类型配置

### 图片文件 (image)
- **支持格式**: PNG, JPEG, JPG
- **文件大小限制**: 最大 10MB
- **最大上传数量**: 5个文件
- **上传接口**: `/api/upload/image`
- **超时时间**: 30秒
- **界面类型**: 图片卡片式 (picture-card)

### 文档文件 (document)
- **支持格式**: PDF, DOC, DOCX, XLS, XLSX
- **文件大小限制**: 最大 50MB
- **最大上传数量**: 3个文件
- **上传接口**: `/api/upload/document`
- **超时时间**: 60秒
- **界面类型**: 文本列表式 (text)

## 使用方法

### 1. 拖拽组件
从组件库拖拽"文件上传"组件到设计画布。

### 2. 配置属性
在属性面板中配置以下属性：

#### 基本属性
- **字段名称**: 组件的唯一标识
- **显示标签**: 显示给用户的标签文字
- **占位符**: 提示文字
- **栅格占位**: 布局宽度 (1-24)

#### 上传配置
- **文件类型**: 选择"图片文件"或"文档文件"
- **接受文件类型**: 自动根据文件类型设置
- **最大文件大小**: 自动根据文件类型设置
- **最大上传数量**: 自动根据文件类型设置

#### 校验规则
- **必填**: 是否必须上传文件
- **禁用**: 是否禁用组件

### 3. 类型切换
当切换文件类型时，系统会自动：
- 更新接受的文件格式
- 调整文件大小限制
- 修改最大上传数量
- 切换上传接口配置
- 更新界面显示样式

## 技术实现

### 配置文件
- `src/config/uploadConfig.ts`: 上传配置和接口定义
- `src/types/designer.ts`: 类型定义
- `src/types/form.ts`: 表单类型定义

### 组件文件
- `src/components/PropertyPanel.tsx`: 属性配置面板
- `src/components/FormField.tsx`: 表单字段渲染
- `src/data/componentLibrary.ts`: 组件库定义

### 扩展接口
目前提供模拟上传接口，实际项目中可以：
1. 替换 `mockUploadFile` 函数
2. 配置真实的 API 地址
3. 添加认证和权限控制
4. 实现进度条和错误处理

## 注意事项

1. **文件验证**: 前端会验证文件类型和大小，但后端也应该进行二次验证
2. **安全考虑**: 限制文件类型和大小，防止恶意文件上传
3. **用户体验**: 提供清晰的文件格式和大小提示
4. **性能优化**: 大文件上传建议使用分片上传
